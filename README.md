# مخطط الحياة

أداة مساعدة لكورس مخطط الحياة: تقييم مجالات الحياة، واكتشاف عنق الزجاجة، وخريطة التنفيذ، والمراجعة الأسبوعية.

- كل البيانات تُحفظ على جهاز المستخدم فقط (localStorage). لا يوجد سيرفر ولا قاعدة بيانات.
- الملفات المنشورة في مجلد `public/`، وتنشرها Cloudflare Workers حسب `wrangler.jsonc`.
- تعمل كتطبيق على الشاشة الرئيسية (manifest + service worker).

## قاعدة التحديثات

الأداة منشورة لعملاء حقيقيين. أي تغيير في شكل البيانات يجب أن يرفع `DATA_V` في `public/index.html` ويضيف خطوة في `migrate()` تحوّل البيانات القديمة بدون أن يضيع منها شيء.
